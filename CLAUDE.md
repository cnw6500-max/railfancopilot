# Railfan Copilot

Kotlin Multiplatform railfan app: Android app in `app/`, shared KMP module in `shared/`
(static XCFramework for iOS), SwiftUI iOS app in `iosApp/` (project generated by XcodeGen
from `iosApp/project.yml`), Firebase Cloud Functions in `functions/`.

- **Unfinished iOS release work: read `docs/IOS_HANDOFF.md` first.** It covers iOS 2.7.6 (53),
  the iOS CI fixes, and the blocked signing secrets.
- Versions: iOS `CFBundleShortVersionString`/`CFBundleVersion` track Android
  `versionName`/`versionCode` in `app/build.gradle.kts`. Bump both together. Play Console has
  used versionCodes up to 50+, so never reuse one.
- Pushes to `main` run the iOS App Store and Android release workflows; add `[skip ci]` to the
  commit message for changes that shouldn't trigger a build.
- Play policy notes and location-permission declaration drafts: `play-policy-prep-2026-10.md`.
- Firebase project: `railfan-copilot`. Deploy functions with `firebase deploy --only functions`,
  indexes with `firebase deploy --only firestore:indexes`.
